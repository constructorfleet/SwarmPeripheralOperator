# Security Policy

SPO runs as privileged host infrastructure. It edits OCI specs and grants device access.

## Reporting

Report vulnerabilities privately through GitHub Security Advisories ("Report a vulnerability" on the Security tab). Do not open public issues for security bugs.

## Scope

In scope: device access granted to a workload that was not allocated it, spoofed task identity, CDI spec or path handling flaws, controller/agent authentication flaws, and secrets in logs or metadata.

## Supported versions

None yet. SPO is pre-release.
